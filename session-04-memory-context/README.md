## What This Session Covers

Session 4 is about giving Claude permanent, personalized context so it stops giving generic answers and starts responding like it actually knows you and your businesses.

Students learn to build their Brain File (CLAUDE.md), understand how the auto-memory system works, and establish a memory maintenance habit that keeps their AI OS running at a high level over time.

**Session tagline:** If Session 3 taught Claude what to do, Session 4 teaches Claude who you are.

## Key Concepts Covered

- **CLAUDE.md (Brain File):** A permanent baseline file Claude reads at the start of every session — your name, businesses, voice, preferences, and standing instructions
- **Auto-Memory System:** How Claude automatically creates memory files from your conversations across four categories (User, Feedback, Project, Reference)
- **Memory Maintenance:** How to keep your memory system accurate over time — correcting, updating, and pruning memories as your business evolves
