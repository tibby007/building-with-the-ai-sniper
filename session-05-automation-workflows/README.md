## What This Session Covers

Session 5 is where the AI OS stops waiting on you and starts running on its own. Students learn the difference between asking Claude to do something and setting up a system that does it automatically.

The hands-on core is building scheduled tasks and routines inside Claude. Around that, students get a plain-English map of the bigger automation toolbox (n8n, Zapier, cron jobs) and an introduction to Claude managed agents that ties the whole course together.

**Session tagline:** If Session 4 gave Claude a brain, Session 5 gives Claude a schedule.

## Key Concepts Covered

- **From Asking to Automating:** The shift from reactive one-time prompts to systems that run on a trigger. Triggers, actions, and routines in plain English.
- **Scheduled Tasks & Routines:** How to set up recurring work inside Claude using plain language, and how to chain steps so one trigger fires a series of actions.
- **The Bigger Toolbox:** What Zapier, n8n, and cron jobs are, in non-developer terms, and exactly when to reach for each one.
- **Claude Managed Agents:** How Claude runs a whole multi-step job on its own, and how it builds on the connectors, skills, and memory from earlier sessions.
- **Choosing the Right Tool:** A decision guide that keeps students from overbuilding. Match the tool to the size of the job.
