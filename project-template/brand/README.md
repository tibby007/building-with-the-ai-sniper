# Brand Assets

This folder is where you store your brand identity files so Claude can reference them when creating content, presentations, documents, or any deliverable that needs to look and sound like YOUR brand.

## What to Put Here

**Visual Identity:**
- Logo files (PNG, SVG, or whatever format you have)
- Brand color codes (hex values, RGB)
- Font names you use

**Voice and Tone:**
- A short document describing how your brand communicates
- Words you always use vs. words you never use
- Example content that nails your brand voice

**Templates:**
- Email signature template
- Document header/footer template
- Social media post templates

## Example Brand File

Create a file called `brand-guide.md` in this folder with something like:

```markdown
# My Brand Guide

## Colors
- Primary: #1A365D (dark blue)
- Secondary: #F6AD55 (warm orange)
- Accent: #48BB78 (green)

## Fonts
- Headlines: Montserrat Bold
- Body: Open Sans Regular

## Voice
- Professional but approachable
- We say "you" not "clients" or "customers"
- We never use buzzwords like "synergy" or "leverage"
- Sentences are short. Paragraphs are short. Get to the point.
```

Claude will read this file and apply your brand standards automatically when creating deliverables in this project folder.
