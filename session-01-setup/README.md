# Session 01: Setup and First Run

This is where it all starts. By the end of this session, you'll have Claude Desktop, Cowork, and Code installed and running on your machine. No more guessing. No more watching tutorials that skip the important parts.

## What's In This Folder

- **student-guide.md** - Your step-by-step walkthrough. Follow this during and after class.
- **lesson-plan.md** - The full session structure (useful if you want to review what we covered).

## What You'll Walk Away With

- Claude Desktop installed and configured
- Your first Cowork session running with a real folder selected
- Claude Code installed (yes, even if you've never touched a terminal)
- An understanding of which tool to use when (Desktop vs. Cowork vs. Code)
- Your first successful interaction with each one

## Before Class

Make sure you have:

1. A Claude account (Pro or Team plan recommended)
2. Admin access on your computer (you'll need to install software)
3. A folder on your computer where you want Claude to work (Desktop, Documents, wherever makes sense for you)

## After Class

Go back through the student guide at your own pace. The best way to learn this stuff is to actually do it. Don't just read it. Open Claude and follow along.
