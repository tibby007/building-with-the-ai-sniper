# Session 3: Skills & Agents — Teaching Claude What to Do

**Course:** Building with The AI Sniper
**Platform:** AI Junkies University (AIJU)

---

## What This Session Covers

In Session 3 we go from giving Claude tools (Session 2) to giving Claude specialized jobs. Students learn what skills are, how to trigger them, and how to build their own using the Skills Generator tool — a custom tool built by Cheryl specifically for this course.

### Students Will Be Able To

- Explain what a skill is and how it differs from a regular prompt
- Trigger built-in skills using natural language phrases
- Use the Skills Generator to build a custom skill from scratch
- Install a skill file into their Claude project and activate it
- Understand the relationship between skills and agents

## Course Tool: The Skills Generator

Cheryl built a custom Skills Generator tool that allows students to create SKILL.md files without any technical knowledge. Students answer a series of questions about the task they want to automate, and the tool outputs a complete, ready-to-install skill file.

**Skills Generator:** https://skill-generator-zeta.vercel.app
