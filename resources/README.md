# Resources

Links to official documentation, community resources, and recommended tools for working with Claude.

## Official Documentation

- **Claude Documentation** - [docs.claude.com](https://docs.claude.com) - The official reference for everything Claude can do. Start here when you have a technical question.
- **Anthropic Support** - [support.claude.com](https://support.claude.com) - Account issues, billing, and general support.
- **Claude API Documentation** - [docs.anthropic.com](https://docs.anthropic.com) - For developers building on the Claude API.
- **MCP Documentation** - [modelcontextprotocol.io](https://modelcontextprotocol.io) - Everything about the Model Context Protocol, including how to build and use MCP servers.

## Getting Claude

- **Claude Desktop** - [claude.ai/download](https://claude.ai/download) - Download the desktop app for Mac or Windows.
- **Claude Web** - [claude.ai](https://claude.ai) - Use Claude in your browser.
- **Claude Code** - Install via npm: `npm install -g @anthropic-ai/claude-code`

## Community

- **AI Junkies University** - [aijunkiesuniversity.com](https://aijunkiesuniversity.com) - Our community. This is where you ask questions, share what you're building, and connect with other students.
- **Anthropic Discord** - Check the official Anthropic site for community channels.
- **Reddit r/ClaudeAI** - Community discussions about Claude use cases and tips.

## Tools Cheryl Recommends

These are tools that work well alongside Claude for building AI-powered business systems:

| Tool | What It Does | Why I Recommend It |
|------|-------------|-------------------|
| GoHighLevel | CRM, automations, funnels | All-in-one for client management. Has an MCP server. |
| n8n | Workflow automation | Self-hostable, connects to everything. Great for complex automations. |
| Notion | Knowledge base, project management | Clean, flexible. Good MCP integration with Claude. |
| HeyGen | AI video creation | Make professional videos with AI avatars. |
| Blotato | Social media scheduling | Schedule across all platforms from one place. |
| Apollo | Sales prospecting | Find leads, enrich contacts. Has an MCP server. |
| Vercel | Web hosting and deployment | Deploy web apps and landing pages fast. |
| Supabase | Database and backend | Easy backend setup. Has an MCP server for Claude. |

## Learning Resources

- **Anthropic Prompting Guide** - [docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview](https://docs.claude.com/en/docs/build-with-claude/prompt-engineering/overview) - Learn how to write prompts that get better results.
- **MCP Server Directory** - Search for available MCP servers through Claude's Cowork mode or the official MCP registry.
